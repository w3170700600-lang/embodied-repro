# SO-101 具身智能复现实录

在一台 **RTX 3050 Laptop（4GB 笔记本显卡）** 和租用的 A4000 / 3090 上，用**同一套 SO-101 单臂硬件、同一个任务、同一批自采数据**，依次复现了三个 VLA 模型。

任务始终是同一句指令：`Grab the green cube`（抓起 3 cm 绿方块并抬离桌面）。

## 三个复现一览

| | [ACT](./act/) | [SmolVLA](./smolvla/) | [π0.5](./pi05/) |
|---|---|---|---|
| 论文 | [2304.13705](https://arxiv.org/abs/2304.13705) (RSS'23) | [2506.01844](https://arxiv.org/abs/2506.01844) | π0.5 (Physical Intelligence) |
| 技术路线 | action chunking + CVAE | VLM 主干 + flow matching | 3B 级 VLM + 动作专家 |
| 参数量 | 51.6 M | 450 M | ~3.6 B（fp32 权重 14.5 GB） |
| 训练硬件 | A4000 16G | A4000 16G | 8 × 3090 |
| 训练量 | 100k 步 / batch 8 / **4h12m** | 15k 步 / batch 32 / **~3h** | 12k 步 / batch 4×8 / **7h13m** |
| 离线指标 | 开环 L1 **1.32°**（基线 10.15°） | 留出集 MAE **1.74°** ≈ 末端 **11.9 mm** | 归一化 MAE **0.3362**（P9 未见位置） |
| 真机结果 | **9/10 = 90%** | **17/17 = 100%**（同一固定点位） | 未做真机（离线阶段） |
| 推理端 | **CPU** i7，161 ms/次 | 3050 4GB，**0.9 GB 显存**，303 ms | 3090 远程服务，40 步/810 ms |

> 真机数字都标了条件，别跨行比较：ACT 的 90% 是 10 轮里的 9 次（95% CI 60~98%）；SmolVLA 的 17/17 全部集中在**同一个摆放点位**（横向跨度仅 0.5 cm），只证明"这一点可重复"，不证明位置鲁棒性。

## 从两个数字读懂这三个复现

**一、30% → 90% 不是调参调出来的。** ACT 复现中，机械臂每轮启动都"朝桌面砸下去"，成功率先是 30%。把每步的模型原始输出落盘后，发现**第 6 轮的第一步输出等于第 5 轮的末尾动作**（差 0.1°）；根因是批处理脚本漏了调用 `policy.reset()`，动作队列里残留上一轮的 40 个动作。补一行，成功率 90%。→ [完整排查链](./act/SO101-ACT-复现组会报告.md)（§5.1）

**二、离线误差 11.9 mm 也能抓得住。** SmolVLA 留出集末端误差平均 11.9 mm，接近 3 cm 方块的横向容差边缘；但真机 17/17 成功。原因是闭环每 20 步重规划一次，开环误差被反馈纠正了——**离线 MAE 是下界估计，不是判决书**。

## 三次复现踩到的共同规律

1. **"模型发疯"九成是调用契约没满足**，不是模型坏了。已确认的三类：内部状态没清空（ACT 的 `policy.reset()`）、初始状态滑出训练分布（SmolVLA 起始姿态漂几度就原地冻结）、执行频率与训练不一致（20 Hz 执行 30 Hz 训出的动作块 = 开环期拉长 1.5 倍）。
2. **行为克隆策略没有"我做完了"这个信号**。SmolVLA 抓起方块后不会停，会继续输出越来越离谱的动作直到自己开爪——必须外挂终止器，用物理量（末端抬升 ≥55 mm 且爪内有物）判定并冻结姿态。
3. **数据的位置多样性比训练步数值钱得多**。π0.5 补 56 条八位置数据后，未见位置误差降 30%；而同一模型 15k→20k 步只改善 0.005°。ACT 那边也有同样的教训：30k 时误判"已饱和"，补测到 80k 误差又降 47%。
4. **单目相机是这套硬件的能力天花板**。ACT 剩余 10% 失败全部是横向偏 1 cm；SmolVLA 的 `elbow_flex` / `shoulder_lift` 两节单独贡献 10.5 mm 和 8.4 mm 误差，平方和超过合成误差——深度歧义基本解释了全部残差。加一路腕部相机是唯一解，调参无效。
